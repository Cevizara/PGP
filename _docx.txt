Building blocks
H(data)
   SHA-1 hash → 160-bit digest
   Returns: digest
EP(PR, data)
   Public-key encryption (RSA) — used for signing with private key
   Returns: E[PR, data]
DP(PU, data)
   Public-key decryption (RSA) — used for verifying signature with public key
   Returns: decrypted data
EP(PU, Ks)
   Public-key encryption of session key with recipient's public key
   Returns: E[PUb, Ks]
DP(PR, encryptedKs)
   Public-key decryption to recover session key
   Returns: Ks
EC(Ks, data)
   Symmetric encryption (CAST-128 / IDEA / 3DES, CFB mode)
   Returns: E[Ks, data]
DC(Ks, data)
   Symmetric decryption
   Returns: decrypted data
Z(data)
   ZIP compression
   Returns: compressed data
Z_inv(data)
   ZIP decompression (Z⁻¹)
   Returns: decompressed data
R64(data)
   Radix-64 (Base64) encoding + CRC
   Returns: ASCII text
R64_inv(text)
   Radix-64 decoding (R64⁻¹)
   Returns: binary data
RNG()
   Random number generator (CAST-128 based, ANSI X12.17)
   Produces unpredictable 128-bit Ks
   Returns: Ks

KEY RING & KEY MANAGEMENT
computeKeyID(PU)
   Key ID = PU mod 2^64 (least significant 64 bits)
   Returns: keyID
generateKeyPair(passphrase, userID)
   Generates PU / PR pair (RSA/DSS)
   Computes H(passphrase) → CAST-128 key
   Encrypts PR with that key: E(H(passphrase), PR)
   Stores entry in Private Key Ring
   Returns: keyID
loadPrivateKey(passphrase, keyID)
   Send side: index Private Key Ring by userID/keyID
   Computes H(passphrase) → CAST-128 key
   Decrypts (DC) the encrypted private key → PRa
   Returns: PRa
loadRecipientPrivateKey(passphrase, keyID)
   Receive side: index Private Key Ring by receiver's Key ID
   Same decryption flow → PRb
   Returns: PRb
getRecipientPublicKey(ID_B)
   Select PUb from Public Key Ring by recipient user ID
   Returns: PUb, keyID
getSenderPublicKey(senderKeyID)
   Select PUa from Public Key Ring by sender's Key ID
   Returns: PUa

Key Ring storage structures
PrivateKeyRing
   Fields per entry: Timestamp, KeyID*, PublicKey, EncryptedPrivateKey = E(H(Pi), PRi), UserID*
   Indexable by KeyID or UserID
PublicKeyRing
   Fields per entry: Timestamp, KeyID*, PublicKey, OwnerTrust, UserID*, KeyLegitimacy, Signatures, SignatureTrust
   Indexable by KeyID or UserID

📤 SENDING — generateMessage (Slide 27 diagram)
buildSignature(M, PRa, keyID_a)
   # Constructs the signature component (slide 22 structure):
   timestamp of signature
   digest = H(M || timestamp)
   signature = EP(PRa, digest) → E[PRa, H(M)]
   leadingTwoOctets of digest
   keyID of sender's PUa
   Returns: signatureComponent
buildMessageComponent(M)
   data, filename, creationTime
   Returns: messageComponent
concat(signatureComponent, messageComponent)
   The || block
   Returns: signature + message
compress(signedMessage)
   X ← Z(X) — compress signature + message
   Returns: compressed X
generateSessionKey()
   Calls RNG() → Ks
   Returns: Ks
encryptMessage(Ks, compressedX)
   EC(Ks, X) — symmetric encrypt
   Returns: E[Ks, X]
encryptSessionKey(PUb, Ks)
   EP(PUb, Ks) — encrypt session key
   Returns: E[PUb, Ks]
buildSessionKeyComponent(encryptedKs, keyID_b)
   keyID of recipient's PUb + E[PUb, Ks]
   Returns: sessionKeyComponent
assembleOutput(sessionKeyComponent, encryptedMessage)
   The final || block → X
   Returns: combined X
radix64encode(X)
   X ← R64(X)
   Returns: ASCII Output
segment(output, maxSize = 50000)
   Splits into mail-safe segments (after R64)
   Session key + signature appear only in first segment
   Returns: segments[]
🎯 Top-Level Send Orchestrator
pgpSend(M, ID_A, ID_B, passphrase, signRequired, confidentialityRequired)
   PRa ← loadPrivateKey(passphrase, keyID_a)
   If signRequired: X ← concat(buildSignature(M, PRa, keyID_a), buildMessageComponent(M))
   X ← compress(X) (Z)
   If confidentialityRequired:
   Ks ← generateSessionKey()
   X ← encryptMessage(Ks, X) (EC)
   PUb ← getRecipientPublicKey(ID_B)
   X ← assembleOutput(buildSessionKeyComponent(encryptSessionKey(PUb, Ks), keyID_b), X)
   X ← radix64encode(X) (R64)
   segments ← segment(X)
   Returns: segments

📥 RECEIVING — receiveMessage (Slide 28 diagram)
reassembleSegments(segments)
Strip mail headers, rebuild original block
Returns: X
radix64decode(X)
X ← R64_inv(X)
Returns: binary X
parseSessionKeyComponent(X)
Extract receiver's Key ID + E[PUb, Ks]
Returns: receiverKeyID, encryptedKs, remainingX
decryptSessionKey(PRb, encryptedKs)
Ks ← DP(PRb, E[PUb, Ks])
Returns: Ks
decryptMessage(Ks, encryptedX)
X ← DC(Ks, E[Ks, X])
Returns: compressed signature + message
decompress(X)
X ← Z_inv(X)
Returns: signature + message
parseSignedMessage(X)
Split into signatureComponent (with sender's Key ID, encrypted digest) + message M
Returns: senderKeyID, encryptedDigest, leadingTwoOctets, M
verifySignature(PUa, encryptedDigest, M, leadingTwoOctets)
recoveredDigest ← DP(PUa, encryptedDigest)
computedDigest ← H(M || timestamp)
Check leadingTwoOctets match (correct key + transmission integrity)
Compare(recoveredDigest, computedDigest)
Returns: isAuthentic (true/false)
🎯 Top-Level Receive Orchestrator
pgpReceive(segments, passphrase, confidentialityRequired, signRequired)
X ← reassembleSegments(segments)
X ← radix64decode(X) (R64⁻¹)
If confidentialityRequired:
(receiverKeyID, encryptedKs, X) ← parseSessionKeyComponent(X)
PRb ← loadRecipientPrivateKey(passphrase, receiverKeyID)
Ks ← decryptSessionKey(PRb, encryptedKs) (DP)
X ← decryptMessage(Ks, X) (DC)
X ← decompress(X) (Z⁻¹)
If signRequired:
(senderKeyID, encryptedDigest, leadingTwoOctets, M) ← parseSignedMessage(X)
PUa ← getSenderPublicKey(senderKeyID)
isAuthentic ← verifySignature(PUa, encryptedDigest, M, leadingTwoOctets)
Returns: { M, isAuthentic }

addPublicKey(PU, userID, ownerTrust)
Insert into Public Key Ring
If owner == self → ownerTrust = ULTIMATE
Else prompt user: UNKNOWN / UNTRUSTED / PARTIAL / COMPLETE
Returns: entry
attachSignature(keyEntry, signerKeyID)
Search ring for signer
Set SIGTRUST = signer's OWNERTRUST (or UNKNOWN)
Returns: updated entry
computeKeyLegitimacy(keyEntry, X, Y)
If any signature has SIGTRUST = COMPLETE → legitimacy = COMPLETE
Else weighted sum: 1/X per always-trusted, 1/Y per usually-trusted
When total weight ≥ 1 → COMPLETE
Returns: legitimacy
revokeKey(PR, keyID)
Issue key revocation certificate signed by owner
Same form as signature cert + revocation indicator
Returns: revocationCert
